# 18650 Battery Cell Database

## Overview

18650 cells are the standard cylindrical lithium-ion format used in VESC-based electric vehicles. This database documents high-quality cells suitable for e-skateboards, e-bikes, and other EV applications.

**Cell Naming Convention:**
- **18** = diameter in mm
- **65** = length in mm (nominal)
- **0** = cylindrical format

## Samsung Cells

### Samsung 30Q (INR18650-30Q)

**The gold standard for e-skateboard battery packs - balanced capacity and discharge rate.**

**Specifications:**
| Parameter | Value |
|-----------|-------|
| Nominal Capacity | 3000mAh |
| Minimum Capacity | 2950mAh |
| Nominal Voltage | 3.6V |
| Max Charge Voltage | 4.2V |
| Discharge Cutoff | 2.5V |
| Max Continuous Discharge | 15A |
| Max Charge Current | 4A |
| Standard Charge | 1.5A (0.5C) |
| Weight | ~48g |
| Dimensions | 18.33mm × 64.85mm |
| Internal Resistance | ~13mΩ |
| Chemistry | NMC (INR) |
| Cycle Life | 250 cycles to 60% at max discharge |

**Real-World Performance:**
- At 10A discharge: ~2900mAh (minimal capacity loss)
- At 15A discharge: ~2800mAh (some voltage sag)
- At 20A: Cell temperature exceeds 70°C (not recommended continuous)

**Best For:**
- 10S4P e-skateboard packs (120A pack current capability)
- Balance of capacity and power
- Medium to high power builds

**VESC Configuration Example (10S4P):**
- Pack Capacity: 12Ah (444Wh)
- Max Pack Current: 15A × 4 = 60A continuous
- Recommended Battery Current: 40-50A per VESC (dual drive)

**Datasheet:** [Samsung INR18650-30Q](https://www.imrbatteries.com/content/samsung_30Q.pdf)

### Samsung 25R (INR18650-25R)

**High-discharge power cell - excellent for high current applications.**

**Specifications:**
| Parameter | Value |
|-----------|-------|
| Nominal Capacity | 2500mAh |
| Minimum Capacity | 2500mAh |
| Rated Capacity (10A) | 2450mAh |
| Nominal Voltage | 3.6V |
| Max Charge Voltage | 4.2V |
| Discharge Cutoff | 2.5V |
| Max Continuous Discharge | 20A (at 25°C) |
| Max Charge Current | 4A |
| Standard Charge | 1.25A (0.5C) |
| Weight | ~43.8g |
| Dimensions | 18.33mm × 64.85mm |
| Internal Resistance | ~13mΩ (AC 1kHz) |
| Chemistry | NCA |
| Cycle Life | 250 cycles to 60% at max discharge |

**Key Features:**
- Updated 25R8 version offers 30A with 80°C temperature cutoff
- Lower internal resistance than 30Q (better for high current)
- Less capacity but higher sustained discharge

**Best For:**
- High-power builds where current matters more than range
- Smaller packs needing high discharge rates
- Hill climbing and aggressive acceleration

**VESC Configuration Example (10S3P):**
- Pack Capacity: 7.5Ah (278Wh)
- Max Pack Current: 20A × 3 = 60A continuous
- Good for single-drive high-power setups

**Comparison to 30Q:**
- 25R: 20A continuous, 2500mAh (best for power)
- 30Q: 15A continuous, 3000mAh (best for range)

**Datasheet:** [Samsung INR18650-25R](https://www.dnkpower.com/wp-content/uploads/2018/04/Samsung-INR18650-25R-Datasheet.pdf)

## LG Chem Cells

**"Chocolate" cell - high capacity with good discharge rate.**

**Specifications:**
| Parameter | Value |
|-----------|-------|
| Nominal Capacity | 3000mAh |
| Minimum Capacity | 2950mAh |
| Nominal Voltage | 3.6V |
| Max Charge Voltage | 4.2V |

| Dimensions | 18.2mm × 65mm |
| Internal Resistance | ~18-20mΩ |
| Chemistry | NMC |
| Cycle Life | 300 cycles at 10A to 70%, 200 cycles at 20A |

- At 10A discharge: ~2925mAh
- At 20A discharge: ~2873mAh

**High-capacity energy cell - maximum range, lower discharge rate.**

|-----------|-------|

| Discharge Cutoff | 2.5V |

**Performance Characteristics:**
| Current | Capacity | Temperature |
|---------|----------|-------------|

## Quality and Authenticity

### Warning About Counterfeits

The 18650 market has significant counterfeit issues:

**Red Flags:**
- Prices significantly below market rate
- "Ultra-fire" or unknown brands claiming 5000mAh+
- Purchases from unverified sellers
- Cells without proper datasheet documentation

**Verification:**
- Buy from reputable suppliers (IMR Batteries, Liion Wholesale, 18650 Battery Store)
- Check manufacturer date codes
- Verify weight and dimensions
- Test capacity and discharge capability

### Recommended Suppliers
- **IMR Batteries** (USA)
- **Liion Wholesale** (USA)
- **18650 Battery Store** (USA)
- **NKON** (Netherlands/EU)
- **Fogstar** (UK)
