# VESC 100/250

## Overview

The **VESC 100/250** is an ultra-high-voltage motor controller designed by Benjamin Vedder, capable of handling up to **100V and 250A continuous** (400A peak). It represents the pinnacle of VESC technology for high-voltage applications, enabling the use of 22S battery packs for extreme performance electric vehicles.

As the 8th generation VESC controller, the 100/250 is specifically engineered for applications requiring both high voltage and high current - such as high-speed electric skateboards, electric surfboards, performance e-bikes, and industrial machinery.

The MKIII is the latest revision, featuring refined components, improved reliability, and the premium build quality expected from official VESC hardware.

## Features

### Motor Control
- **DC, BLDC, FOC (sinusoidal)** operation modes
- **Three battery-sided shunts** for current measurement
- **Adjustable current filters**
- Sensored or sensorless operation + hybrid mode
- HFI (High-Frequency Injection) including Silent HFI
- VSS (Vedder Sensorless Startup)
- Field weakening support
- Sensorless position control capable
- Up to **150K ERPM** drivable (motor/system dependent)

### Sensor Support
- Hall sensors
- ABI encoder
- AS5047/AS5X47U encoder
- SIN/COS encoder (RMB29 on COMM port)
- TS5700N8501 encoder (single and multiturn)
- MT6816 encoder
- BISSC encoder
- TLE5102 encoder
- Custom encoder support

### IMU (Inertial Measurement Unit)
- **9-axis IMU** (accelerometer + gyroscope)
- ±2/±4/±8/±16 g full scale
- Used for balancing applications, orientation sensing

### Connectivity
- USB (Micro USB)
- 2x UART ports
- CAN bus with UAVCAN support
- SPI and I2C
- PWM in/out
- SWD port for debugging and real-time data
- AUX port (12V/5V supply)
- Sensor port for motor sensors
- PPM port for RC receivers
- Wireless connectivity via VESC Express accessory

### Power Management
- **Hibernation mode** - Wake up via power switch (momentary NC)
- **Automatic hibernation** with adjustable timer
- Consumes just **20µA when hibernating**
- Automatic power-off capability
- Roll-to-start (can be disabled)
- 2x programmable GPIO pins

### Advanced Features
- **Regenerative braking** with configurable limits
- **Traction control** for multi-motor setups
- Throttle curves and ramping for all input sources
- Separate acceleration and brake curves
- Seamless 4-quadrant operation
- Motor revolution, amp-hour, watt-hour counting
- Real-time data analysis via all communication ports
- Full scripting support (QML and LISP)
- Mobile app support (Android/iOS via Bluetooth/WiFi accessory)
- Speed, distance, battery state display

### Input Sources
- PPM signal (RC servo)
- Analog input
- NRF Nyko Kama Nunchuck
- UART commands
- CAN commands

### Protection Features
- Low/high input voltage protection
- High motor current protection
- High input current protection
- High regenerative braking current protection (separate limits for motor and input)
- High RPM protection (separate limits per direction)
- Over-temperature protection (MOSFET and motor)
- Adjustable soft back-off strategies

## Physical Characteristics

### Housing
- **Precision CNC aluminum heatsink housing**
- **Black hard anodized coating**
- Non-conductive finish for safety
- Integrated mounting holes
- Solid block T6 aluminum construction

### Cable Configuration (Standard)
- Battery cables: 3x 10cm 4mm core 1036-strand silicone coated cable (SAB)
- XT90H connectors on battery side (3x female)
- Motor phase cables: 14x 10cm 4mm core 1036-strand silicone coated cable
- 4mm female bullet connectors (GC4010-F) on motor side
- XT90 cable length: ~70mm
- Motor cable length: ~120mm

- **150,000 ERPM maximum**
- High-voltage allows lower KV motors for same speed
- Better efficiency with lower KV/higher voltage combination

## Key Differences from VESC 75/300

| Feature | VESC 100/250 | VESC 75/300 |
|---------|-------------|-------------|
| Max Voltage | 100V | 75V |
| Max Battery | 22S | 16S |
| Continuous Current | 250A | 300A |
| Peak Current | 400A | 450A |
| Shunt Design | Battery-sided | Phase-sided |
| Preferred Use | High voltage | High current |
| Generation | 8th gen | 7th gen |

### Design Philosophy
- **VESC 100/250**: Optimized for high-voltage operation (22S) with very high current
- **VESC 75/300**: Optimized for maximum current (300A) at moderate voltages (16S)

### Shunt Design Note
The VESC 100/250 uses **battery-sided shunts** rather than phase-sided shunts. This is a different design approach that affects current measurement characteristics. Both designs are effective but behave slightly differently under certain conditions.

## Known Issues and Considerations

### Voltage Safety
- **Critical**: Voltage spikes must not exceed 100V
- Proper precharge circuits recommended for large capacitors
- 22S fully charged = 92.4V (within safe margin)

### Battery Requirements
- Requires high-quality, high-discharge battery cells
- 22S operation requires experienced user knowledge
- Proper BMS absolutely essential

### Thermal Management
- Large aluminum case provides significant heatsinking
- Air/water circulation important for sustained high-current operation
- Mounting to additional heatsink recommended for continuous duty

### Cost
- Premium pricing (~£300-400)
- Professional-grade components justify cost
- Targeted at serious builders and professionals

## Installation Considerations

### Mechanical
- Mounting holes provided for secure attachment
- Aluminum case can be bolted to external heatsinks
- Size requires adequate enclosure space (141 x 82 x 18mm)

### Electrical
- Heavy-gauge wiring essential (4mm² recommended)
- Quality connectors required (XT90 minimum)
- Proper fusing recommended
- Precharge circuit advised for large systems
