# VESC 75/300

## Overview

The **VESC 75/300** is a high-power, high-current motor controller designed by Benjamin Vedder, featuring an impressive **300A continuous current rating** at up to **75V** (16S). It is the 7th generation VESC controller and represents the pinnacle of current-handling capability in the standard VESC form factor.

Engineered for the most demanding electric mobility and industrial applications, the VESC 75/300 sets a standard for power, reliability, and customization. It is ideal for applications requiring massive torque and sustained high-current operation, such as electric boats, hydrofoils, high-performance e-bikes, and industrial machinery.

The MKIV is the latest revision, featuring refined power delivery, enhanced thermal management, and premium build quality.

## Features

### Motor Control
- **DC, BLDC, FOC (sinusoidal)** operation modes
- **Three phase-sided shunts** for precise current measurement on all motor phases
- **Adjustable current and voltage filters** (full phase filters)
- **Three individual gate drivers** for optimal switching
- Sensored or sensorless operation + hybrid mode
- HFI (High-Frequency Injection) including Silent HFI
- VSS (Vedder Sensorless Startup)
- Multiple HFI modes:
  - 45 Deg V0V7 HFI (Silent)
  - 45 Deg V0 HFI
  - Coupled V0V7 HFI (Silent)
  - Coupled V0 HFI
- Sensorless position control capable
- Field weakening support
- Up to **150K ERPM** drivable (motor/system dependent)

### Sensor Support (Comprehensive)
- Hall sensors
- ABI encoder
- AS5047/AS5X47U encoder
- SIN/COS encoder (RMB29 on COMM port)
- TS5700N8501 encoder (single and multiturn)
- MT6816 encoder
- BISSC encoder
- TLE5102 encoder
- Custom encoder support

### IMU (Inertial Measurement Unit)
- **9-axis IMU** (accelerometer + gyroscope)
- ±2/±4/±8/±16 g full scale accelerometer
- Used for balancing applications, orientation sensing, and advanced control

### Connectivity
- USB (Micro USB)
- 2x UART ports
- CAN bus with UAVCAN support
- SPI and I2C
- PWM in/out
- SWD port for debugging and real-time data
- AUX port (12V/5V supply for external devices)
- Sensor port for motor sensors
- PPM port for RC receivers
- 2x programmable GPIO pins
- Wireless connectivity via VESC Express accessory

### Power Management
- **Hibernation mode** - Wake up via power switch (momentary NC)
- **Automatic hibernation** with adjustable timer
- Consumes just **20µA when hibernating** (less than battery self-discharge)
- Automatic power-off capability
- Roll-to-start (can be disabled)
- Power button options

### Advanced Features
- **Regenerative braking** with configurable limits (separate for motor and input)
- **Traction control** for single and twin motor setups
- Throttle curves and ramping for all input sources
- Separate acceleration and brake throttle curves
- Seamless 4-quadrant operation
- Motor revolution, amp-hour, watt-hour counting
- Real-time data analysis via all communication ports
- Full scripting support (QML and LISP)
- Mobile app support (Android/iOS via Bluetooth/WiFi accessory)
- Speed, distance, Wh usage per distance, precise battery indicator
- Current consumption, duty cycle, and power display
- Self-adjusting analogue displays

### Input Sources
- PPM signal (RC servo)
- Analog input
- NRF Nyko Kama Nunchuck
- UART commands
- CAN commands

### Protection Features
- Low/high input voltage protection
- High motor current protection
- High input current protection
- High regenerative braking current protection (separate limits for motor and input)
- High RPM protection (separate limits per direction)
- Over-temperature protection (MOSFET and motor)
- Adjustable soft back-off strategies

## Use Cases

### Best For
- **Electric hydrofoils** (e-foils) - sustained 300A operation for water sports
- **Electric boats** - Marine propulsion requiring high torque
- **High-performance e-bikes** - Steep hill climbing and rapid acceleration
- **Electric mountainboards** - Extreme off-road performance
- **Combat robots** - High-burst current for weapon systems
- **Industrial machinery** - Sustained high-power operation
- **Electric motorcycles** - Light EV applications
- **Towing applications** - High-torque requirements

### Recommended Motor Power
- 3000W to 20,000W continuous
- Peak power up to 22.5kW (brief periods)

### Recommended Battery
- **12S to 16S LiPo/LiIon** (44.4V to 67.2V)
- **16S (67.2V)** recommended for maximum performance
- High-discharge cells required (150A+ continuous discharge capability)
- Battery must be capable of supporting 300A continuous draw

### ERPM Capabilities
- **150,000 ERPM maximum**
- Phase-shunt design provides excellent performance at all speeds
- Optimized for high-current FOC operation at any ERPM

## Key Design Features

### Phase-Sided Shunts
Unlike the VESC 100/250, the 75/300 uses **phase-sided shunts** (three individual shunts on motor phases). This is considered the preferred design choice by Benjamin Vedder because:
- More accurate motor current measurement
- Better FOC performance
- Smoother operation across speed range

### High Current Capability
The 75/300 is specifically designed for applications requiring:
- Maximum torque
- Sustained high-current operation
- Large acceleration demands
- Heavy load handling

### Thermal Management
The CNC'd aluminum housing:
- Dissipates excess heat during flat-out operation
- Maintains cool operating temperature
- Allows mounting to additional cooling structures
- Can be water-cooled with appropriate modifications

## Comparison: VESC 75/300 vs VESC 100/250

| Feature | VESC 75/300 | VESC 100/250 |
|---------|-------------|--------------|
| Max Voltage | 75V | 100V |
| Max Battery | 16S | 22S |
| Continuous Current | 300A | 250A |
| Peak Current | 450A | 400A |
| Shunt Design | Phase-sided | Battery-sided |
| Preferred Use | High current | High voltage |
| MOSFETs | Lower resistance | Higher voltage rated |
| Capacitance | More (80V caps) | Standard |
| Generation | 7th gen | 8th gen |

### Selection Guide

**Choose VESC 75/300 if:**
- You need maximum current (300A+)
- Running 16S or lower voltage
- Prioritizing torque over top speed
- High-current applications (hydrofoils, heavy vehicles)

**Choose VESC 100/250 if:**
- You need 22S capability (100V)
- Prioritizing top speed over maximum current
- High-voltage efficiency is important
- Lower KV motors at higher voltage preferred

## Known Issues and Considerations

### Critical Requirements
- **Voltage spikes must not exceed 75V**
- Battery must support 300A continuous discharge
- Proper cooling essential for sustained operation
- Quality wiring and connectors mandatory (XT90 minimum)

### Battery Considerations
- Most battery packs cannot sustain 300A continuous
- Battery current typically lower than motor current
- At high speeds and loads, battery current approaches motor current
- Ensure battery BMS can handle discharge requirements

### Thermal Management
- Aluminum case provides significant heatsinking
- Additional cooling may be needed for continuous 300A operation
- Air/water circulation improves sustained performance
- Temperature monitoring via VESC Tool recommended

### Installation
- Robust mounting required for vibration resistance
- Proper cable management essential (thick cables don't bend easily)
- Multiple smaller cables recommended over single thick cable
- Precharge circuit recommended for large capacitor bank
