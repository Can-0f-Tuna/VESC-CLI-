# VESC Labs Controllers (2025+)

## Overview

In 2025, **VESC Labs** was founded by Benjamin Vedder and key members of the VESC project. This Sweden-based company now serves as the official manufacturer of premium VESC hardware, taking over from Trampa Boards (which was the previous exclusive manufacturer).

The VESC Labs product line represents the current state-of-the-art in VESC motor controllers, with new designs that push the boundaries of voltage, current, and integration.

## Philosophy

VESC Labs was created with the mission:
1. Produce premium VESC Original electronics
2. Support the VESC ecosystem with revenue flowing back to open-source software development
3. Develop hardware ranging from tens of watts to hundreds of kilowatts
4. Provide full integration with VESC software from day one

## Key Features Across VESC Labs Lineup

### Standard Features (All Models)
- Full VESC Tool compatibility
- Benjamin Vedder firmware support
- Open-source software integration
- IMU (accelerometer + gyroscope)
- CAN bus communication
- USB-C connectivity (most models)

### Premium Features (Select Models)
- **ESP32** with Wi-Fi and Bluetooth (Duet, Pronto, Maxim series)
- **4GB Integrated Storage** for logging and scripts (Duet, Pronto, Maxim series)
- **Potted/Waterproof** design (Pronto, Maxim series)
- **High-current 12V outputs** (up to 8A on Maxim/Pronto)
- **Multiple ADC inputs** (up to 5 on premium models)
- **39-pin IO connector** (Maxim series)

## Transition from Trampa

As of 2025:
- **VESC Labs** is the new official manufacturer
- **Trampa Boards** continues selling legacy VESC devices
- Trampa devices receive same support as other third-party vendors
- VESC Labs focuses on new hardware development
- All legacy Trampa VESCs remain compatible with VESC software

## Selection Guide

### By Application

**Electric Skateboard (Single Motor)**
- Budget: VESC Minim
- Standard: VESC Classic 100V
- High Power: VESC Classic+ 100V

**Electric Skateboard (Dual Motor)**
- Budget: VESC Duet XS (60V or 100V)
- Standard: VESC Duet XS 100V
- High Power: VESC Duet

**E-Foil / Marine**
